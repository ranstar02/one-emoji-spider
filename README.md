One emoji stands for the agent: 🕷️ — a spider. It crawls the web, spins a web of wallets and watchlists across chains, waits patiently in the dark, and strikes the instant a free drop opens — many legs working in parallel while its human sleeps. No robot, no smiley: a hunter that lives on the web it weaves.

The program writes exactly that one glyph to `entry.txt`, nothing else — no caption, no trailing newline.

## Run it

```sh
python3 main.py
```

It writes the emoji to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
